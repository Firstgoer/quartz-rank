# Quartz Rank 1.9

### New game versions
- **Burning Crusade Classic / Anniversary** support (2.5.6).
- **WoW: Forever** support (1.60.1), together with **Quartz Redux**.
- Updated for **Classic Era** 1.15.9.

### Quartz Redux
- Works with both the original Quartz (Classic Era, Burning Crusade) and Quartz Redux (Forever). The matching one is installed automatically as a dependency.
- Target names and Quartz's "on target" style are now shown exactly as Quartz formats them, with the rank added to the spell name.

### Options
- Settings are now a single panel, like Quartz's own modules, marked with a grey **[mod]** tag in the Quartz options.
- Existing settings are kept.

### Translations
- Options, addon list title/description and messages are translated into German, Spanish, French, Italian, Korean, Portuguese, Russian and Chinese.

### Fixes
- No longer creates global variables that could conflict with other addons.
- More robust rank detection across languages.
